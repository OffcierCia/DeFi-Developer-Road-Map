# Roadmap source

`../Fix2024.svg` is generated from `roadmap.txt`.

- `+` = Must Know, `~` = Extended; indent with two spaces per level.
- Rebuild: `cd roadmap-src && python3 build_roadmap.py roadmap.txt && mv roadmap-teal.svg ../Fix2024.svg && rm -f roadmap-github-*.svg`
- Python 3 standard library only.
